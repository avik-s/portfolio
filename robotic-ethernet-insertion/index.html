Vision-Guided Robotic Ethernet Insertion

Autonomous RJ45 insertion in NVIDIA Isaac Sim

Isaac Sim 6.0 Python OpenCV YOLOE Lula IK PhysX

System overview

This end-to-end manipulation system guides a Franka Panda robot through RJ45 insertion in NVIDIA Isaac Sim 6.0. Synchronized eye-in-hand RGB stereo cameras provide the visual signal; YOLOE segmentation, Lula inverse kinematics, and GPU-accelerated PhysX simulation close the loop from perception to contact.

Stereo perception & port-center estimation

  • Reconstructs the port's visible RGB front rim from the segmented camera views.
  • Uses the rim's diagonal intersection to estimate a perspective-correct opening center.
  • Triangulates the 3D target from the stereo pair without runtime ground truth or tuned XYZ offsets.

Visual-servo / kinematic handoff

A multi-frame stability check locks a world-frame target before the wrist camera becomes occluded. The controller then hands the target to a kinematic final approach, using bounded Cartesian motion so the tool can settle without chasing a disappearing visual feature.

Insertion state machine

  • Separates visual acquisition and final insertion into two explicit control stages.
  • Uses ToolCenter feedback and quaternion orientation hold to keep the connector aligned.
  • Checks attachment state before reporting a completed insertion.

Results

The verified simulation run completed every commanded insertion while maintaining tight pose error at the port.
